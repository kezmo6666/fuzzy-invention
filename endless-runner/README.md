# Neon Runner

A simple 3D endless runner built with [Three.js](https://threejs.org). Navigate through neon obstacles in a dark, futuristic world.

## How to Run

Open `index.html` in a modern web browser. Use the arrow keys to move left and right and the space bar to jump. Survive as long as possible to increase your score.

No additional installation steps are required as the game pulls Three.js from a CDN.
